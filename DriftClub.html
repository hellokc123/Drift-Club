Drift Club — a browser drifting game.

Everything you see and hear is generated in code: low-poly cars and maps, a custom WebGL renderer, synthesized engines, tyre squeal and music.

  • Game design, code, art & music: built with Claude
  • Rendering: WebGL (no external engine required)
  • Multiplayer: Node.js + WebSockets room server
  • Car and place names are fictional

Thanks for playing. Go sideways responsibly.
